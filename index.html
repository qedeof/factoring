Factoring Reference Guide

Quick lookup techniques and key rules for algebraic expression factoring.

1. Greatest Common Factor (GCF)

Always the first step! Identify numbers/variables shared by every term.

$ab + ac = a(b + c)$
Ex: $6x^2 + 9x = 3x(2x + 3)$

2. Difference of Squares

Applies when subtracting two perfect squares ($a^2 - b^2$).

$a^2 - b^2 = (a - b)(a + b)$
Ex: $x^2 - 25 = (x - 5)(x + 5)$

3. Trinomials ($x^2 + bx + c$)

Find two numbers $p$ and $q$ that multiply to $c$ and add up to $b$.

$x^2 + (p+q)x + (pq) = (x + p)(x + q)$
Ex: $x^2 + 7x + 12 = (x + 3)(x + 4)$

4. AC Method ($ax^2 + bx + c$)

Multiply $a \cdot c$. Find factors of $ac$ that add up to $b$. Split the middle term and factor by grouping.

$2x^2 + 7x + 3 \rightarrow ac = 6$
Factors: $6$ and $1$ $\rightarrow 2x^2 + 6x + 1x + 3 = (2x+1)(x+3)$

Factoring Strategy Flowchart

Step 1

Pull out the Greatest Common Factor (GCF) if any exists.

Step 2: 2 Terms?

Check for Difference of Squares ($a^2 - b^2$).

Step 3: 3 Terms?

Use product-sum strategy ($a=1$) or AC Method ($a>1$).

Step 4: Check

Multiply factors back out (FOIL) to verify correctness.
